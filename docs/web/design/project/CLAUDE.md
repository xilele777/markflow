# markflow前端 · 设计规则（项目内长期生效）

## 视觉方向（已确定）
- **工坊 · 浅色**：IBM Plex 全家族（IBM Plex Sans / IBM Plex Sans SC / IBM Plex Mono）+ 蓝色点缀 `#2f6df0` + 冷调浅灰中性 + 发丝边框。
- **全程禁止深色背景 / 深色侧栏**，外壳保持浅色中性。
- 共用语义色：状态色（就绪/解析中/部分成功/解析失败）、分类色（标注/流式/结果），颜色只表达状态与分类，不做装饰。
- 令牌集中在 `tokens.jsx` 的 `THEME`；共享原子组件也在其中。

## 列表页 / 内容区规范
- **内容区不要加「页面大标题 + 描述性副标题」文字块**（例如「数据集 / 管理标注…·N 个·N 样本」）。意义不大、占空间、影响观感；页面位置由顶栏面包屑表达即可。
- **不显示「共 N 条」这类汇总文字**。
- 工具栏（搜索框 + 筛选 + 主操作按钮如「新建」）统一**右对齐放在同一行**。
- 列表**底部需有分页**：页码 + 上一页/下一页 + 跳转到某页。
- 表格中**创建人不加头像圆圈**，直接显示姓名文字。
- 操作列**不用「…」图标**，使用明确的文字链接（如「查看详情」）。
- 数据集列表需包含 **ID（编号）列**。
- 行密度：紧凑 40px 单行。

## 文案规范
- **面向用户，不写技术性术语**：如「后缀决定解析格式」「直传 OSS」「ossPath」等开发视角的话不要出现在界面上。文件格式提示统一写「支持 Jsonl 格式文件」。
- **空间（workspace）由侧栏左下角的空间切换器表达**，表单内不再让用户选择/重复展示「所属空间」。
