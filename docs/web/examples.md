# 本地导入样例

相对于前端应用目录 `apps/web/`：

| 目录 | 内容 |
|---|---|
| `examples/datasets/` | 用户情绪识别、主播意图识别、图生视频的 JSONL 数据集样例 |
| `examples/users/` | 原 `import-users-30.jsonl` 本地用户导入样例 |

这些文件从根目录归类移动，内容未修改，仍由 `.gitignore` 的 `*.jsonl` 规则排除；它们是现有工作区的本地资料，干净 clone 不包含这些文件，也不是构建或自动化测试的依赖。用户管理页支持 JSONL / CSV 解析后逐个调用创建接口，格式示例由 `src/features/user/parse.ts` 提供；本地样例未在本轮重新导入验收。

需要可重复验收数据时运行 [浏览器验收脚本](testing.md)，脚本自行创建测试数据。不要把本地样例当作历史业务数据迁移结果或发布包内容。
