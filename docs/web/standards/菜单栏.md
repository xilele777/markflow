# 菜单栏（侧栏导航）

> **何时使用**：实现全局布局的左侧导航、或新增 / 调整菜单项时必读。本篇只锁定**菜单栏（左侧栏）**。色值见《配色规范.md》。

## 一、结构（自上而下三段）

固定侧栏，**宽 224px**，`surface` 白底 + 右侧 1px `hairline` 分隔线；竖向三段：

1. **顶部 · 品牌**：几何 logo + 「灵枢」（display 字体 17px 700）+ 其下 `LINGSHU`（mono 9.5px，字距 0.18em，weak 色）。
2. **中部 · 菜单**：占满中间，把底部顶到最下。
3. **底部 · 空间切换器**。

## 二、菜单形态

- **纯文字，无导航 / 装饰图标**（功能性小图标只在内容区用，侧栏不放）。
- **平铺，不折叠**：所有项一律展开，不做可折叠二级分区。
- **灰字分组标题**：weak 色（`#9aa0ab`）、11px、不可点击，仅视觉分组。
- **菜单项**：高 34px、圆角 6、字号 13.5；默认 `text` 色 400 字重。
- **选中态**：底色 `#eef2fb` + 文字加粗(600) + **左侧 3px 蓝色 accent bar**（`accent #2f6df0`）。

## 三、分组与菜单项（锁定）

| 分组（灰字标题） | 菜单项 |
|---|---|
| 资产 | 数据集 |
| 任务 | 标注任务、我的任务组 |
| 系统 | 工作空间、用户管理、标注工具、AI 配置 |

> 顺序与归属即上表。新增页面先确认归到哪个分组，不随意调整既有归属。

## 四、底部 · 空间切换器

- 固定在侧栏**最底部**（顶部一条 `border` 分隔）。一个可点的盒子：左侧 26px 方块（空间名首字，accent 色）+ 空间名（13px）+ 其下空间编码（mono 10px，weak 色）+ 右侧 chevron。
- 点击切换当前工作空间；**多数列表 / 表单依赖「当前空间」上下文，表单内不再让用户选所属空间**（见《文案规范.md》）。

## 五、不放进侧栏的东西

- **当前用户 / 头像**：在顶栏右上角（账户入口）；侧栏不放人员信息。

## 备注

- 菜单项可能按当前用户角色显隐；「角色 → 可见菜单项」映射规则**另定**，不在本篇。
