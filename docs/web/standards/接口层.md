# 接口层（API 客户端）

> **何时使用**：写任何调后端的代码前必读。后端字段 / 枚举 / 方法以 `markflow/docs/接口文档.md` 为准。

## 一、基本约定

- 方法：以接口文档为准（一律 **POST**，`application/json`）；路径以 `/api` 开头。
- 基地址：开发期用 **Vite proxy** 把 `/api` 代理到 `127.0.0.1:8080`（中间件 / 后端需开发者手动开 SSH 隧道 + 起服务）。
- **统一响应包络**：`{ success, code, message, data, timestamp }`；分页接口顶层额外有 `{ total, pageNum, pageSize }`、`data` 为列表。

## 二、HTTP 客户端（axios 单例）

- `baseURL = '/api'`。
- **请求拦截**：注入 `Authorization: Bearer <token>`（从 store / localStorage）。
- **响应拦截**：
  - 拆包络：`success=true` → 返回 `data`（分页接口返回 `{ list, total, pageNum, pageSize }`）；`success=false` → 抛业务错误（带 `code` / `message`），调用方或全局用 `Toast` 提示。
  - `401` / 鉴权失效 → 清 token + 跳 `/login`。
  - 网络错误 / 5xx → 统一错误 `Toast`。
- **安全**：日志与任何输出都不得打印 token / apiKey / password。

## 三、与 TanStack Query 配合

- 每个 `features/<x>/api.ts` 导出 **typed 纯函数**：`getCaseList(req): Promise<PageResult<CaseListItem>>`。
- 页面用 `useQuery` / `useMutation` 包这些函数，拿 `isLoading` / `isError` → 驱动《组件清单》的 `LoadingState` / `ErrorState` / `EmptyState` 三态。
- 列表分页：参数 `{ pageNum, pageSize, ... }`；query key 含全部参数。
- 写操作（create / submit 等）用 `useMutation`，成功后失效相关 query（刷新列表）。

## 四、类型

- `types/` 定义包络泛型：`ApiResponse<T>` / `PageResponse<T>`。
- 各 feature 定义 `XxxRequest` / `XxxResponse`，字段对齐后端（camelCase；枚举用 number code，对应《状态映射.md》）。

## 五、鉴权与上下文

- 登录（`login`）拿 token → 存 store + localStorage。
- `getCurrentUser` 拿 `user + workspaces + roles` → 存 store（供菜单 / 操作显隐，见《权限可见性.md》）。
- **当前空间**（`spaceCode`）来自侧栏空间切换器，存 store；需要 `spaceCode` 的接口（数据集 / Case 列表等）由封装自动带上，页面不重复传。
