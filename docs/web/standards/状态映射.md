# 状态映射

> **何时使用**：渲染任何「状态 / 类型」标签前必读。这是各业务枚举 → {颜色 tone, 显示文案} 的**唯一真源**。
> tone 取自《配色规范.md》的 `STATUS` / `CATEGORY`；**组件不得自建状态色 map、不得硬编码色值**。后端 code 含义以 `markflow/docs/接口文档.md` 为准。

## 八、纯文本枚举（不上色，中性标签或纯文字）
- **标注工具类型**（labelToolType）：1=内置、2=IFRAME —— 中性标签（`fill` 底 / `sub` 字）。
- **派发策略**（strategy）：1=先到先得、2=固定分配 —— 纯文字。
- **空间角色**（role）：1=标注员、2=审核员、3=标注管理员 —— 纯文字。
- **用户状态**：0=正常（`done`）、1=禁用（`idle`）。

## 九、动作色（按钮，非标签）
- 质检 **通过**（reviewAction=1）：成功色（`done` 系，绿）。
- 质检 **不通过**（reviewAction=0）：失败色（`failed` 系，红）。
