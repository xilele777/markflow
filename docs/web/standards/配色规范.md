# 配色规范

> **何时使用**：写任何带颜色的前端界面（标签、状态、分类、强调、按钮、链接、选中态）前必读。
> 视觉方向：**工坊 · 浅色**（IBM Plex 全家族 + 蓝色强调 + 冷调浅灰中性 + 发丝边框，全程无深色背景）。

## 一、核心原则

1. **颜色分三类用途**：① 中性灰（外壳：背景/卡片/边框/文字）；② 交互强调蓝（主按钮/链接/选中/焦点）；③ 语义色（状态色 + 分类色，只表达"数据信息"）。
2. **不做装饰**：不用大面积彩色块、不用渐变；颜色只为"区分信息"或"标识可交互/当前态"。
3. **Token 是唯一真源**：所有颜色取自下表（落地后即 `THEME` + `STATUS` + `CATEGORY` 三组）。**禁止在页面/组件里硬编码色值，也禁止各页自建状态色 map**。

## 二、中性色（外壳）

| token | 值 | 用途 |
|---|---|---|
| `canvas` | `#f5f6f8` | 画布底色 |
| `surface` | `#ffffff` | 卡片 / 侧栏 / 顶栏 |
| `fill` | `#eef0f3` | 浅填充（表头底、chip 底、hover） |
| `hairline` | `#e9ebef` | 发丝分隔线（表格行、卡片内分隔） |
| `border` | `#dce0e6` | 控件 / 卡片边框 |
| `text` | `#171a1f` | 主文字 |
| `sub` | `#586070` | 次文字 |
| `weak` | `#9aa0ab` | 弱文字 / 占位符 / 分组标题 |
| `selected` | `#eaecf1` | 通用选中底 |

## 三、强调色（交互蓝）

| token | 值 | 用途 |
|---|---|---|
| `accent` | `#2f6df0` | **实心主按钮**、文字链接、选中菜单 accent bar、输入焦点环、分页当前页、筛选 chip 选中 |
| `accentSoft` | `#e8eefe` | 强调浅底（选中 chip 底等） |
| `activeBg`（菜单选中底） | `#eef2fb` | 侧栏当前菜单项底色 |

> 强调蓝**只用于上述交互语义**，不滥用、不做装饰。

## 四、字体

| token | 字体 | 用途 |
|---|---|---|
| `display` | `IBM Plex Sans` | 标题 / 拉丁文 |
| `body` | `IBM Plex Sans SC` | 正文（中文） |
| `mono` | `IBM Plex Mono` | ID / 编号 / 版本号 / 数字 / 编码 |

圆角基数 **6**（派生：标签 4、控件 6、卡片 7）。主按钮 **实心蓝**（accent 底 + 白字）。

## 五、状态色板（语义，浅底 + 中调字；圆点取 fg 色）

| token | 底 | 字/圆点 | 文案 | 用于 |
|---|---|---|---|---|
| `ready` / `done` | `#e7f4ec` | `#2c7a52` | 就绪 / 已完成 | 数据集就绪、任务完成、case 已结束 |
| `running` | `#e9eff8` | `#3a5ea8` | 进行中 | 解析中、标注中、质检中、case 运行中 |
| `partial` | `#faf0d9` | `#8a6312` | 部分成功 | 部分成功、case 已暂停 |
| `failed` | `#fbe9e7` | `#a8423a` | 失败 | 解析失败、打回重标 |
| `idle` | `#f1f2f5` | `#565b66` | 空闲 | 待分配、未启动、待执行 |

## 六、分类色板（仅区分，避开状态色相）

| token | 底 | 字 | 文案 | 用于 |
|---|---|---|---|---|
| `annotate` | `#eceefb` | `#454fae` | 标注 | 数据集类型「标注」、标注类 stage |
| `stream` | `#e2f1ee` | `#277268` | 流式 | 数据集类型「流式」 |
| `result` | `#f2eafa` | `#6b46a8` | 结果 | 数据集类型「结果」、质检类 stage |

## 七、落地约定（AntD）

- 注入 `ConfigProvider` 主题 token：`colorPrimary=accent`、`colorBgLayout=canvas`、`colorBgContainer=surface`、`colorBorder=border`、`colorBorderSecondary=hairline`、`colorText=text`、`colorTextSecondary=sub`、`colorTextTertiary=weak`、`borderRadius=6`、`fontFamily=IBM Plex…`。
- **状态 / 分类标签不用 AntD Tag 的预设颜色**，统一用本规范封装的 `Tag`（分类）/ `StatusDot`（状态）组件，颜色取自 `STATUS` / `CATEGORY`（见《状态映射》）。
- 各业务状态 → 取哪个 tone、显示什么文案：**只在《状态映射.md》定义**，组件不得自行写死。

> 间距 / 尺寸 / 阴影见《组件清单.md》《页面模板.md》。
