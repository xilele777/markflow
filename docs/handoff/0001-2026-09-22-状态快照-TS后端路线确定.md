## 5. 关键事实速查

- 灵枢 Java 包 `com.onlyactwo.lingshu`；控制器在 `controller/`，几乎全为 `POST /api/<模块>/<动作>`，例外 `GET /api/user/getCurrentUser`；登录 `POST /api/auth/login` → `{token}`。
- 响应包络 `{success, code, message, data, timestamp}`；分页顶层加 `total/pageNum/pageSize`。
- 枚举 code：TaskStatus 1 PENDING_DISPATCH / 2 LABELING / 3 REVIEWING / 4 DONE / 5 REWORK；TaskType 1 AI_LABEL / 2 LABEL / 3 AI_REVIEW / 4 FIRST_CHECK / 5 RECHECK；TaskGroupType 1 PERSONAL / 2 AI_PRE_LABEL_POOL / 3 LABEL_POOL / 4 AI_PRE_REVIEW_POOL / 5 REVIEW_POOL / 6 RECHECK_POOL；TaskGroupStatus 1 PENDING / 2 RUNNING / 3 DONE；CaseStatus 1 NOT_STARTED / 2 RUNNING / 3 PAUSED / 4 FINISHED；WorkspaceRole 1 LABELER / 2 REVIEWER / 3 LABEL_ADMIN（接口返回英文名）；UserStatus 0 NORMAL / 1 DISABLED；DatasetType 1 ANNOTATION / 2 STREAM_ANNOTATION / 3 RESULT；UploadStatus 1 PARSING / 2 READY / 3 PARSE_FAILED；LabelToolType 1 BUILTIN / 2 IFRAME；ReviewAction 0 REJECT / 1 PASS；SampleType 1 ANNOTATION / 2 REVIEW；DataSourceType 1 DATASET / 2 STREAM；StageType 字符串 `aiPreLabel/label/aiPreReview/review/recheck`（阶段 1–5，对应池 2–6）。
- 派发：幂等键 `(caseId, taskType, dataSampleId)`；锁 `dispatch:case:{caseId}:pool:{poolType}`；策略 FCFS=1 / FIXED_RATIO=2；AI 阶段消费"已派发"事件后调用与人相同的提交接口；提交成功后事务提交再发"已完成"事件 → 下一阶段入池并派发。
- sys_config 键：`jwt.secret`、`jwt.expireSeconds`、`tos.config`、`ai.configList`（apiKey 目前明文，重写时加密）。
- 前端：`shared/api/http.ts` 只在 HTTP 401 跳登录，其他非 2xx 弹 `response.data.message`；`LoginPage` 固定跳 `/dataset`，应改用 `pickHomePath`；`vite.config.ts` 代理 `/api` → `127.0.0.1:8080`。
- 本机：Node 24、Docker 29 + Compose v5、JDK 21（不再需要）、无 Maven。
