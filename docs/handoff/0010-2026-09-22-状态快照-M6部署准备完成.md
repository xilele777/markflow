## 2. 已准备资产

### 后端可观测性

- 新依赖 `prom-client@15.1.3`，每个 AppContext 独立 Registry，API/worker 共用，测试间不共享指标。
- `GET /api/metrics`：独立 `MARKFLOW_METRICS_TOKEN`，至少 32 字符；缺省 404，错误 token 401；常量时间比较，no-store。不经过 Redis 全局限流，Redis 故障仍能返回明确的采集失败。抓取依赖失败/3s 超时返回 503，不返回健康的旧 gauge。一次在途采集，等待所有查询 settled 才释放，避免故障时堆积。
- HTTP duration histogram：method/route/status，使用匹配的路由模板，未匹配/鉴权前拒绝归 unmatched，不用原始 URL 或用户/case 标识作为标签。
- pool gauge：运行/暂停 case 中池组的待分配/重做任务，按 taskType 1–5 聚合；个人在手/结束 case 排除，空阶段归零。
- AI attempt counter：success / retryable_failure / permanent_failure；每次重试独立计数，skipped 不计。四队列的各状态 gauge、outbox 待投递数与最老等待秒数、Node 默认进程指标。
- `GET /api/health`：PG + Redis + S3 HEAD 桶 + 四个 BullMQ 队列（只读操作、暂停也视为不就绪），全部正常才 200，否则 503；每项 2s 上限、短缓存/在途探测复用、异常不回显内部信息。新增非敏感 releaseId；不验证 LLM、对象写权限、浏览器 CORS 或 worker 消费进度。
- `MARKFLOW_SERVER_HOST` 默认 127.0.0.1；`MARKFLOW_RELEASE_ID` 由打包后的 PM2 配置自动设置，开发默认 development。没有新增迁移、没有变更业务接口契约。

### 发布与运维

- `scripts/package-release.mjs`：本地组装配对的后端 dist + 前端 dist，白名单复制；记录前后端 SHA、dirty 状态、构建时间，生成前端 release.json。不含 .env、node_modules、Git 或测试数据。

- `scripts/smoke.sh` / `smoke.mjs`：health/login/getCurrentUser/匿名与坏 token 401、SPA/缓存/安全头/缺失资源404；发布时核对 API releaseId 和前端 release.json，避免旧 upstream/静态目录误通过。
- `deploy/ecosystem.config.cjs`：单实例 fork，用 Node --env-file 读 shared/server.env，PM2 env 只含 NODE_ENV 与非敏感版本号；发布脚本以干净父环境调用 PM2。须专用运行用户/daemon，不能复用以前混入密钥的 dump。
- `deploy/nginx/`：HTTPS 静态 + API 反代、安全头/CSP、静态缓存与 SPA fallback、大小写不敏感禁止公网 metrics；可选 MinIO 独立 HTTPS 域名，保留 Host/URI 以免破坏签名。

3. 真实 HTTPS 直传、对象写/读/下载、反代/CSP/TOS、PM2/systemd 以及云端防火墙均需实机验证；localhost 回归不能替代。
4. 首次上线采用维护窗口。current 切换后旧标签页可能仍请求旧 hash 的懒加载文件；手册明确刷新要求，无感升级的跨 release 静态资源保留尚未实现。发布存在短暂进程重启间断。
5. DB 自动向前迁移仍沿用既有行为。未来有破坏性迁移不能直接依赖代码回滚，需兼容迁移/停写/备份专项流程。
