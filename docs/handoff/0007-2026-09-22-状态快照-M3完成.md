## 2. M3 落下的决定（后续沿用）

规则表 §10 是对 Java 疑点的最终裁定，这里只记实现层面的约定：

1. **outbox 用法**：所有「事务内产生的队列消息」一律 `outbox.enqueueTx(trx, msg)` 落行，事务提交后 `outbox.deliver(ids)`；投递成功即删行，失败 `attempts+1`、`next_retry_time = now + 30s`，`startRepublisher` 每 30s 扫 `status=1 AND next_retry_time <= now` 重投（每轮 100 条）。jobId 缺省 `outbox-<id>`，dataset-parse 沿用 `version-<id>`。业务代码不再直接 `queue.add`。
2. **派发引擎**（`dispatch-engine.ts`）：入池幂等键 `uk_task_case_type_sample`；已 DONE 的 task 再入池即「重开」（status=1、round+1、回池、清 annotator）；出池在 Redis 锁 `dispatch:case:{caseId}:pool:{poolType}`（wait 3s / lease 30s）内开事务 `FOR UPDATE SKIP LOCKED` 取候选，条件更新移入个人组；`dispatchPool` 先查 case RUNNING；预派发只补到 `preDispatchSize`（默认 3）；FIXED_RATIO 配额 `floor(sampleCount*ratio/100) - countByGroup`。`dispatchPoolQuietly` 只记日志不抛，用于提交后补题。
3. **提交路径统一**：人与 AI 都走 `submitLabelTaskInternal / submitReviewTaskInternal`（事务内写结果样本 + 完成 task + outbox `task-completed`，提交后 deliver + 给提交者补题）。结果集 dataset 在首次提交时 lazy 创建（锁 `dataset_version:case:{id}:label_result`，名 `结果集_case{id}`，type RESULT，不出现在数据集列表）。
4. **驳回**：原执行者仍 active → 留组、status=5、round+1、`claimTime` 重置为 now；否则回池（status=5 保留、清 annotator）并立即 `dispatchPool(prevStage)`。驳回目标是 AI 阶段时重新投递 `task-dispatched` 让 AI 重做。驳回不发 `task-completed`。
5. **AI 执行器**（`ai-task-executor.ts`）：`execute(taskId, attempt)` 返回 `done | skipped | failed`；LLM 超时 120s；失败分类：超时 / 网络 / 429 / 5xx 为瞬时，抛出让 BullMQ 按队列默认 attempts 3 重试；非 JSON 响应、4xx、配置缺失为永久，不重试；两类都写 `label_task.ext.aiFailure {code, message, attempt, time}`，任务停留在 AI 个人组等自动回收。`task-dispatched` 消费者并发 2，其余队列并发 1。
6. **自动回收**：进程内定时器每 60s，锁 `${queuePrefix}:schedule:task_auto_recycle`（wait 0 / lease 120s），每轮最多 500 条候选；REWORK 保持 5，其余置 1，清 annotator 回池后 `dispatchPool`。
7. **导出**：`case-export` 消费者按结果版本分页流式读（`selectPageByVersionAfterId`），CSV（RFC 4180）/ JSONL 经 `putObjectStream`（lib-storage 分片）上传到 `export/case/{caseId}/{yyyyMMdd}/{uuid32}.{fmt}`；`case.ext.lastExport = {status, format, objectKey, operator, time, error?}`，不落 URL；详情接口按 objectKey 现签 1h 预签名 GET。无行数上限。
8. **鉴权收紧**（规则表 §2、4.1、4.5、5.1）：case 列表/详情需空间成员或系统管理员；task 读需 annotator / 系统管理员 / 空间 LABEL_ADMIN；save / submit 只允许 annotator。
9. **Kysely 坑**：`sql\`CASE WHEN status = ${x}\`` 的绑定参数会被 pg 推断为 text，赋给 integer 列报错，常量必须用 `sql.lit()`（`recycleToPool` 已改）。
10. 路由层 zod 只校类型；业务枚举（`sampleType`、`reviewAction`、`stage.type` 等）在服务层用 `isXxxCode` 校，错误码沿用 Java 文案（`error-codes.ts`）。
