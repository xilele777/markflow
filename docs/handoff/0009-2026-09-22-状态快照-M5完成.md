## 2. M5 落下的决定（后续沿用）

1. **case 状态机**：`updateCaseStatus` 只接受 2 / 3 / 4；RUNNING ⇄ PAUSED，RUNNING / PAUSED → FINISHED，FINISHED 终态（`CASE_STATUS_TRANSITION_INVALID`）；同状态幂等成功。锁 `case:status:{id}`。
2. **暂停语义**：派发引擎 `dispatchPool` / `dispatchToMember` 对 PAUSED 直接返回 0（不抛），`enqueueToPool` 对 RUNNING / PAUSED 都放行（在手任务提交后下一阶段样本不丢），只有其它状态抛 `CASE_NOT_RUNNING`；保存 / 提交在 PAUSED 仍允许，FINISHED 拒绝（`CASE_FINISHED`）。恢复时对流程内每个池 `dispatchPoolQuietly`。
3. **自动结束**：末阶段 task 完成后（提交路径 `after` 钩子 + `task-completed` 消费者 `nextStageType=null` 兜底）检查「末阶段 DONE 数 = 首阶段 task 数且全 case 无未完成 task」→ RUNNING → FINISHED，operator `SYSTEM`，通知创建人 `CASE_FINISHED`。手工结束不发通知。
4. **个人组统计**：`label_task_group` 个人组的 `total_count` = 组内 task 数、`done_count` = DONE 数、`status` = 有 task 且全 DONE → 3 否则 2，在派发 / 完成 / 驳回 / 回收 / 重开的同一事务内用一条 SQL 重算（`refreshPersonalGroupStats`）；池子的 `total_count` 仍是累计入池数、status 不动。`update_time` 随之刷新，「我的任务组」按活跃度排序。
5. **通知模型**：收件人按 `username`（citext），四类 `TASK_DISPATCHED`（人工阶段派题后一条汇总，AI 阶段不发）/ `TASK_REJECTED`（留组驳回给原人；回池不发）/ `CASE_DEADLINE` / `CASE_FINISHED`；`refType` `TASK_GROUP` → `/groups/:id`，`CASE` → `/case/:id`。写入与业务同事务；读 / 标记只作用于本人；`markRead` 不传 ids 为全部、最多 200 个。无清理定时器（repo 有 `deleteReadBefore` 备用）。
6. **截止时间**：存 `label_case.ext.deadline`（毫秒），`ext` 更新改为 `COALESCE(ext,'{}') || patch`，`lastExport` 与 `deadline` 互不覆盖；创建 / 修改时须晚于当前时间（`DEADLINE_INVALID`），`null` 清除并清零 `deadlineReminderAt` / `deadlineOverdueAt`；定时器每分钟扫运行中 case：≤ 24h 提醒一次、逾期通知一次，收件人 = 创建人 + 空间 LABEL_ADMIN 去重；已暂停 / 已结束不扫。文案时间按 `LINGSHU_TIMEZONE`。
7. **用户禁用**：鉴权中间件验签后查库，禁用或不存在 → `401 UNAUTHORIZED`（文案「账号已被禁用或不存在」），进程内缓存 10s，`updateStatus` 通过回调让本进程缓存立即失效（多实例最多延迟 10s）；不能禁用自己（`CANNOT_DISABLE_SELF`）。登录仍返回 200 `USER_DISABLED`。
8. **FIXED_RATIO 配额**保持按版本总样本数计（规则表 9.14「沿用 Java」），不再列为待办。
9. **前端状态点**：`StatusDot` 不传 children 时显示的是色板默认文案（`STATUS.running.label='进行中'`），业务枚举必须显式传 `metaOf(...).label`；本次修了 case 列表 / 详情，其它页面已是显式传。
10. **e2e 运行方式**：Git Bash 里直接 `node e2e/x.mjs` 可能只打印 `stdin is not a tty` 就退出，用 `cmd //c "node e2e\\x.mjs > log 2>&1"`；`Modal.confirm` 的按钮在 `.ant-modal-confirm` 内。

- 暂停中仍允许保存 / 提交（决定 2）；若产品要「暂停即冻结」，在 `requireWritableCase` 里把 PAUSED 一并拒绝即可，测试 `m5-features` 的暂停用例需同步改。
