## 2. M4 落下的决定（后续沿用）

1. **测试放源码旁**：`src/**/*.test.ts(x)`，vitest `globals: true`；组件测试用 `createMemoryRouter` + `vi.mock` 掉 `../api` 与 `@/shared/components/Toast`；http 层测试不 mock axios，而是替换 `http.defaults.adapter` 走真实拦截器链。
2. **懒加载边界**：只有登录页同步引入；`Suspense` fallback 是居中 Spin，壳内外共用 `suspend()` 包装。新页面一律 `lazy(() => import(...))`。
3. **嵌入页 ↔ 执行页协议**：嵌入页每次 `setField` 后立即 `postMessage({type:'markflow:embed-result', taskId, state:'dirty'})`，保存中 / 成功 / 失败分别发 `saving` / `saved` / `error`（同源校验 `e.origin`）；执行页提交前若状态非 `saved` / `error` 则最多等 4s。IFRAME 类型工具不参与此协议，也不做客户端校验（无 pageSchema），仍由后端 `submitLabelTask` 最终校验。
4. **客户端校验口径**：`deriveOutputFields(pageSchema)` 得到的输入组件字段全部视为必填；`undefined / null / 空串 / 空数组` 算未填，`false / 0` 算已填（BooleanInput / RateInput 语义）。校验对象是 `getTaskResult(taskId, 1)` 返回的**已保存**结果，不是 iframe 内存态。
5. **自动保存并发**：同一时刻只有一个 `saveTaskResult` 在飞；保存期间的编辑标 dirty，保存完成后再走一次 debounce；卸载时若 dirty 则尽力发一次（不等待）。手动「保存结果」按钮会取消待触发的自动保存并立即保存 + toast。
6. **Web Vitals 上报只在 PROD**：`import.meta.env.PROD` 为 false 时 `initWebVitals` 空操作，dev / 单测不会打后端；后端公开接口对非白名单 / 非 JSON / 负值一律 204 不落表，限流 429 带 `Retry-After`。
7. **离线状态条只用浏览器信号**：`navigator.onLine` + `online` / `offline` + `visibilitychange`，没有心跳探测；无头 Chrome 下 `Network.emulateNetworkConditions` 不会自动改 `navigator.onLine`，验收脚本要同时派发事件。
8. **体积门禁不在 `npm run build` 里**：`build:check` 才跑，CI 的 build job 显式执行；本地日常构建不被预算阻断。
9. **rules-of-hooks 修法固定**：Puck `ComponentConfig.render` 只做 `(props) => <XxxRender {...props} />`，hook 全在 `XxxRender` 里；新组件照此写。
