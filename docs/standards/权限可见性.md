# 权限可见性（角色 → 菜单 / 操作）

> **何时使用**：配菜单显隐、页面 / 操作鉴权前。
> ⚠️ 一期后端鉴权部分未做，前端先按本表做**显隐**，真实权限以后端为准。**本表为建议，待最终确认**（见文末待确认点）。

## 一、角色来源

`getCurrentUser` 返回 `isSystemAdmin` + `workspaces[].roles`（`1=标注员 / 2=审核员 / 3=标注管理员`）。系统管理员 = `isSystemAdmin`；其余角色按**当前空间**判定。

## 二、菜单可见性（建议）

| 菜单项 | 可见角色 |
|---|---|
| 数据集 | 标注管理员、系统管理员 |
| 标注任务 | 标注管理员、系统管理员 |
| 我的任务组 | 标注员、审核员 |
| 工作空间 | 系统管理员 |
| 用户管理 | 系统管理员 |
| 标注工具 | 系统管理员（标注管理员只读） |
| AI 配置 | 系统管理员、标注管理员 |

## 三、操作可见性（建议）

| 操作 | 可执行角色 |
|---|---|
| 新建 / 编辑 数据集、Case | 标注管理员、系统管理员 |
| 创建用户、创建工作空间、写标注工具 | 系统管理员 |
| 写 AI 配置 | 系统管理员（列表标注管理员可读，密钥不回显） |
| 进入标注执行 | 该组标注员 |
| 进入质检执行 | 该组审核员 |

## 四、落地

- **菜单过滤**与**路由守卫**都读 store 里的当前用户（`isSystemAdmin` + 当前空间 `roles`）。
- 无权访问 → 重定向到有权页面或显示 403 空态。

## 五、待确认点

1. 管理员（标注管理员 / 系统管理员）是否也进「我的任务组」（即是否也作为执行人）？
2. 「标注工具 / 工作空间」是否给标注管理员只读入口？
3. 一期是否干脆只按 `isSystemAdmin` 粗粒度（管理员看全部、非管理员只看「我的任务组」），细粒度等后端鉴权补齐再做？
