# 工程结构

> **何时使用**：搭项目骨架、新建目录 / 文件、配路由、接主题前必读。

## 一、技术选型（骨架）

| 维度 | 选型 | 说明 |
|---|---|---|
| 构建 | Vite + React 18 + TypeScript | |
| UI | Ant Design + `ConfigProvider` 主题 token | token 来自《配色规范.md》，集中在 `app/theme.ts` |
| 路由 | React Router v6 | |
| 服务端状态 | TanStack Query（react-query） | **所有接口调用走它**，统一 loading / error / 缓存，驱动三态 |
| 客户端状态 | Zustand | 只放轻量全局态：当前用户、当前空间、token |
| HTTP | axios + 拦截器 | 详见《接口层.md》 |
| 表单 | AntD Form | 见《组件清单.md》 |
| Lint | ESLint + Prettier | 规则：禁内联 style、禁硬编码十六进制色值（走 token）、禁裸用未封装组件 |

## 二、目录结构

```text
src/
├── main.tsx
├── App.tsx                  # ConfigProvider(theme) + Router + QueryClientProvider
├── app/
│   ├── theme.ts             # 《配色规范》token → AntD ConfigProvider（全局唯一）
│   ├── router.tsx           # 路由表（见 §四）
│   └── layout/              # AppShell / Sidebar / Topbar（壳）
├── shared/
│   ├── api/                 # http 客户端、响应包络类型、通用请求封装
│   ├── components/          # 《组件清单》的封装件（DataTable / StatusDot / Tag / Drawer / Modal / FormPage …）
│   ├── constants/           # 枚举 → 颜色/文案（对应《状态映射》STATUS / CATEGORY / 各 code 表）
│   ├── store/               # zustand（auth / workspace）
│   ├── hooks/  └── utils/
├── features/                # 按业务模块分（每个含 api.ts / pages/ / components/）
│   ├── auth/                # 登录
│   ├── dataset/  case/  taskgroup/  exec/
│   ├── workspace/  user/  labeltool/  aiconfig/
└── types/                   # 公共类型（响应包络、枚举）
```

每个 `features/<x>/`：`api.ts`（typed 接口函数）+ `pages/`（页面）+ `components/`（该模块专属件）；可复用件一律上提到 `shared/components/`。

## 三、命名约定

- 组件 PascalCase；feature 目录小写；hooks `useXxx`；**api 函数名与后端接口同名**（`createCase` / `getCaseList` …）。
- 类型 `XxxRequest` / `XxxResponse`，字段对齐后端（camelCase、枚举用 number code）。
- 枚举的颜色 / 文案集中在 `shared/constants`（对应《状态映射》），**不散落进组件**。

## 四、路由地图

| path | 页面 | 布局 | 备注 |
|---|---|---|---|
| `/login` | 登录 | 全屏 | 无壳 |
| `/` | → 重定向 `/dataset` | — | |
| `/dataset` | 数据集列表 | 壳内 | |
| `/dataset/new` | 新建数据集 | 壳内·独立页 | |
| `/dataset/:id` | 数据集详情 | 壳内 | 版本行操作开抽屉 |
| `/dataset/:id/version/new` | 新建版本 | 壳内·独立页 | |
| `/case` | 标注任务列表 | 壳内 | |
| `/case/new` | 新建标注任务 | 壳内·独立页 | |
| `/case/:id` | 标注任务详情 | 壳内 | |
| `/my-groups` | 我的任务组 | 壳内 | |
| `/my-groups/:gid` | 任务组详情 | 壳内 | |
| `/exec/label/:taskId` | 标注执行页 | 全屏 | 无壳 |
| `/exec/review/:taskId` | 质检执行页 | 全屏 | 无壳 |
| `/workspace` | 工作空间列表 | 壳内 | 详情用抽屉（无独立路由） |
| `/user` | 用户管理 | 壳内 | 新建用弹窗 |
| `/labeltool` | 标注工具列表 | 壳内 | 详情用抽屉 |
| `/aiconfig` | AI 配置列表 | 壳内 | 新建 / 编辑用弹窗 |

- **全屏路由**（`/login`、`/exec/*`）渲染在 `AppShell` 之外；其余在壳内。
- **简单实体详情用抽屉**（无独立路由）；复杂详情（Case / 数据集）走独立路由。
- 修改密码：头像菜单内弹窗，不单独占路由。

## 五、主题落地

`app/theme.ts` 把《配色规范》token 映射成 `ConfigProvider` 的 `theme.token` + 必要的 `theme.components` 覆盖（`colorPrimary=accent`、`borderRadius=6`、`fontFamily=IBM Plex…` 等），**全局只此一处**。状态 / 分类色不进 ConfigProvider，由封装的 `Tag` / `StatusDot` 读《状态映射》。
