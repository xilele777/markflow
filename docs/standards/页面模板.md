# 页面模板

> **何时使用**：新建任何页面前，先在此对号入座选一种模板，再用《组件清单.md》的封装组件拼装。

## 全局布局
- 框架内页：`AppShell` = 侧栏(224) + 顶栏(56) + 内容区(内边距 22–28、区块间距 16)。
- 全屏页：脱离 `AppShell`（登录、标注 / 质检执行页）。

## 一、列表页模板
顺序：**工具栏 → 表格 → 分页**。
- **内容区不加「页面大标题 + 描述副标题」**（位置由顶栏面包屑表达）。
- `Toolbar`：搜索 + 筛选 + 主操作(新建)，**同一行右对齐**。
- `DataTable`：行高 44；操作列=文字链接（如「查看详情」），**不用「…」**；创建人=纯文字；ID / 编号 / 版本 / 数字=mono；**不显示「共 N 条」**。
- 底部 `Pagination`（页码 + 上 / 下一页 + 跳页）。
- 覆盖 空 / 加载 / 错误 三态。
- 适用：数据集、标注任务、我的任务组、工作空间、用户、标注工具、AI 配置 的列表（同一模板换列）。

## 二、详情页模板
- 顶部 `PageBackHeader`（或面包屑）。
- `DetailHeaderCard`（基本信息：标题 + 状态/标签 + 右侧操作 + `MetaGrid`）+ 若干 `SectionCard` 分区。
- **Case 详情**：头卡 + `StageProgressBar` 各阶段（池中待领 / 个人在做 / 已完成）。
- **数据集详情**：头卡 + 版本列表(`DataTable`)，行操作开 `Drawer`（样本预览前 10 / 解析失败明细）。

## 三、表单页模板（独立页）
复杂表单走独立页：`PageBackHeader` + 分区 `SectionCard` + 底部 `FooterActionBar`（取消 + 主提交，校验未过则禁用）。
- **表单内不再选「所属空间」**（空间由侧栏切换器表达）。
- **Case 新建**：基本信息 → 流程编排(`StageStep` 固定顺序勾选) → 人员/AI 分配(每启用阶段一张 `ConfigCard`；人工卡含 `MemberRow` + 策略联动比例)。动态：数据源切数据集版本显隐、工具联动 AI 配置、固定分配比例和=100。
- **数据集新建 / 新建版本**：上传区(拖拽 / 点选) + 基本信息；上传成功后才可提交。

## 四、执行页模板（全屏）
全屏接管（无侧栏 / 顶栏）：`ExecToolbar`(上窄) + `ExecFrame`(下大 iframe)。
- **标注页**（taskType 2）：右侧 上一题 / 下一题 / 提交标注；无平台保存按钮。
- **质检页**（taskType 4/5）：右侧 上一题 / 下一题 / 通过(绿) / 不通过(红)；点「不通过」开 `RejectModal` 填意见(必填)。
- 提交 / 通过 / 不通过成功后**自动跳下一题**；最后一题处理完显示「本组已全部处理完」+ 返回任务组。

## 五、弹窗 vs 抽屉 vs 独立页（选择规则）
| 形态 | 用于 |
|---|---|
| **弹窗 Modal** | 简单新建 / 编辑（工作空间、AI 配置、用户）、危险操作确认、质检驳回填意见 |
| **抽屉 Drawer** | 实体详情 / 侧栏查看（工作空间详情·成员、数据集样本预览 / 解析明细） |
| **独立页** | 复杂表单（Case 新建、数据集上传）、复杂详情（Case 详情、数据集详情） |
