## 4. 接口调用清单

### 4.1 `src/types/api.ts`
```ts
interface ApiResponse<T> { success: boolean; code: string; message: string; data: T; timestamp: number }
interface PageResponse<T> extends ApiResponse<T[]> { total; pageNum; pageSize }   // 分页字段在顶层
interface PageResult<T> { list: T[]; total; pageNum; pageSize }                      // 拆包后
interface PageRequest { pageNum: number; pageSize: number }
class ApiError extends Error { code: string }   // code = 业务错误码字符串，如 'CASE_NOT_FOUND'
```
成功 `code` 为 `'SUCCESS'`；所有枚举用 number code；时间戳为毫秒 Long。

### 4.2 http 封装（`shared/api/http.ts`）

## 5. 横切机制

### 5.1 http 拦截器（`shared/api/http.ts`，99 行）
- `axios.create({ baseURL: '/api', headers: {'Content-Type':'application/json'} })`。
- 请求：`getToken()`（zustand getState）非空 → `Authorization: Bearer <token>`。
- 响应成功分支：若 body 不是含 `success` 的对象 → 原样放行；`success=true` → 放行；`success=false` → `toast.error(message)` + `reject(new ApiError(code, message))`。
- 响应错误分支：HTTP 401 → `onUnauthorized()`（清 auth store + workspace store，`window.location.assign('/login')`，非 /login 时）→ reject `ApiError('UNAUTHORIZED')`；其它 → `toast.error(data.message || '网络异常')` + reject 原 AxiosError。
- 包络拆解在 `post/get`（返回 `res.data.data`）和 `postPage`（读取顶层 `total/pageNum/pageSize`）。
- 403/权限不足不特判，只 toast 后端 message。
- **注意**：markflow Java 后端所有失败都返回 HTTP 200（见后端索引 §4.3），所以这里的 401 分支对原后端实际上不可达，token 过期只会 toast「未登录」而不跳转。TS 重写按规划 0002 对 UNAUTHORIZED 返回 401，正好激活这条分支。

### 5.2 Stores（zustand 5，无 persist 中间件，手写 localStorage）
- `useAuthStore`：`token`（初始化读 `localStorage['markflow.token']`）、`user: CurrentUser|null`（不持久化，刷新后由 RequireAuth 补拉）、`setToken/setUser/clear`。`getToken()` 供拦截器。
- `useWorkspaceStore`：`spaceCode`（`localStorage['markflow.spaceCode']`）、`workspaces[]`（不持久化）、`setSpace/setWorkspaces/clear`。`getSpaceCode()` 供 `postScoped`。

### 5.3 权限模型（`shared/auth/permissions.ts`）
- 角色字符串常量（对齐后端 `workspaces[].roles`）：`LABEL_ADMIN`、`REVIEWER`、`LABELER`；系统管理员来自 `user.isSystemAdmin`。空间角色数字码（成员分配入参）：1 标注员 / 2 审核员 / 3 标注管理员（`RoleCode`、`ROLE_TEXT`、`ROLE_META`）。
- `useCurrentRoles()` 按 `spaceCode` 找当前空间角色，派生：
  - `canManageData = isSA || isLabelAdmin`
  - `canManageSystem / canViewTaskProgress / canViewAiConfig / canViewLabelTool / canWriteAiConfig = isSA`
  - `canExportResult = isSA || isLabelAdmin`
- `pickHomePath(perms)` 见 §3。

### 5.4 菜单（`app/layout/nav.ts`）
三分组：资产（数据集·dataAdmin）；任务（标注任务·dataAdmin，我的任务组·全员，我的贡献·全员，任务进度·SA）；系统（工作空间·SA，用户管理·SA，标注工具·SA，AI 配置·`canViewAiConfig`）。`filterNav` 去空组；`matchNav` 最长前缀匹配给侧栏选中态 + 顶栏面包屑（`/groups/:gid` 不匹配任何菜单，故面包屑为空；`/my-groups/:gid` 别名就是为了保持选中态）。

### 5.5 会话/登录流
1. `LoginPage`：`login()` → `setToken` → `getCurrentUser()` → `setUser` + `setWorkspaces` + `setSpace(workspaces[0])` → toast → `navigate('/dataset', {replace:true})` 固定跳转（第 119 行；非管理员会被 RequireRole 再弹到 `/my-groups`；忽略 `RequireAuth` 传来的 `state.from`）。失败 `clearAuth()`。
2. 刷新：token 在、user 不在 → `RequireAuth` 用 `['auth','me']` 拉 `refreshCurrentUser`，期间显示 Spin。
3. 切空间：`Sidebar.WorkspaceSwitcher` `setSpace` + `getCurrentUser` mutation 刷新 user；列表页 queryKey 含 spaceCode 自动重拉。
4. 退出：Topbar `clearAuth + clearWorkspace + navigate('/login')`。
5. 创建空间/加成员后调 `refreshCurrentUser()` 刷新切换器。

- `app/theme.ts`：`palette`（canvas #f5f6f8、surface #fff、fill、hairline、border、text #171a1f、sub、weak、selected、accent #2f6df0、accentSoft、activeBg）、`fonts`（display/body/mono IBM Plex）、`sizing`（controlHeight 34、rowHeight 44、sidebarWidth 224、topbarHeight 56、radius 6）；`antdTheme.token` + `components`（Layout/Button/Table/Card/Input/Select/InputNumber/Pagination/Drawer）覆盖。
