# 组件清单

> **何时使用**：写任何页面前必读。这是全站**唯一允许使用的组件库**。
> **铁律**：页面只用下列封装组件拼装；**不手搓 `div + inline style`、不裸用 AntD 原始组件**（统一经封装，保证主题 / 尺寸 / 状态一致）。颜色走《配色规范》token + 《状态映射》，禁硬编码。
> 落地技术：**AntD + 定制主题 token**；下表「AntD 落地」列给出每个封装对应的 AntD 基座。设计原型（`docs/design/project`）是**视觉目标**，不照搬其手写结构。

## 全局尺寸（统一）
- 控件高 **34px**（按钮 / 输入 / 筛选 / select）；表格行 **44px**、表头 44px、单元格内边距 `0 16px`、表头底 `fill`。
- 圆角基数 **6**（标签 4、卡片 7）；按钮内边距 `0 14`；标签内边距 `4×8`。
- 侧栏 224、顶栏 56、内容区内边距 `22–28`、区块间距 16。

## 一、布局骨架
| 组件 | 用途 | AntD 落地 |
|---|---|---|
| `AppShell` | 侧栏 + 顶栏 + 内容容器 | Layout / Sider / Header / Content |
| `Sidebar` | 左侧导航（详见《菜单栏.md》） | 自定义 |
| `Topbar` | 顶栏：左面包屑（**无页面大标题**）+ 右 版本号(mono weak) + 头像(退出) | Breadcrumb / Avatar |
| `PageBackHeader` | 「← 返回」(功能图标) + 标题 | 自定义 |
| `SectionCard` | 分区卡片（title / 可选 desc / 可选 step 序号） | Card |
| `FooterActionBar` | 表单页底部 sticky 操作栏（高 64，hairline 顶，右对齐 取消 + 主提交，校验禁用） | 自定义 |

## 二、数据展示
| 组件 | 用途 | AntD 落地 |
|---|---|---|
| `DataTable` | **全站表格唯一入口**：列驱动 `{key,label,width/flex,align,render}`，行高 44、表头 `fill`、行间 hairline。操作列=文字链接(accent)、**不用「…」**；创建人=纯文字；ID/编号/版本/数字=mono | Table（统一封装） |
| `Pagination` | 上一页 / 页码 / 下一页 + 「跳至 N 页」，右对齐，列表底部必有 | Pagination |
| `Toolbar` | 搜索 + 筛选 + 主操作，**同一行右对齐** | 自定义容器 |
| `SearchField` | 搜索输入（放大镜功能图标 + 占位） | Input |
| `FilterSelect` | 筛选（标签 + chevron，选中 `accentSoft` 底） | Select / Dropdown |
| `Tag` | 分类 / 类型标签（浅底 + 中调字，圆角 4），tone 取 `CATEGORY` | 自定义（不用 AntD Tag 预设色） |
| `StatusDot` | **状态唯一组件**：6px 圆点(取 fg) + 文案，tone 取 `STATUS` | 自定义 |
| `MetaGrid` / `MetaItem` | 详情「基本信息」键值网格（label 上 / value 下，mono 可选） | 自定义 |

## 三、详情与反馈
| 组件 | 用途 | AntD 落地 |
|---|---|---|
| `DetailHeaderCard` | 详情页头卡：标题 + 状态/标签 + 右侧操作按钮 + hairline + `MetaGrid` | Card |
| `Drawer` | 右侧抽屉（遮罩 + 滑入，头 title/副标题 + ✕，滚动体）。用于实体详情、数据集样本预览 / 解析明细 | Drawer |
| `Modal` / `ConfirmModal` | 居中弹窗。用于简单新建 / 编辑、危险操作确认、质检驳回填意见 | Modal |
| `Toast` | 轻提示（自动消失） | message / notification |
| `EmptyState` / `LoadingState` / `ErrorState` | 空 / 加载 / 错误三态，**列表、详情、抽屉都要覆盖** | Empty / Skeleton / Result |

## 四、表单
| 组件 | 用途 | AntD 落地 |
|---|---|---|
| 表单原子 | `Input / Textarea / Select / Num / Switch / Segmented(单选段) / Lbl`，**各页不得自写字段样式** | Form.Item + Input / Select / InputNumber / Switch / Radio.Group |
| 校验 | AntD Form 规则 + 字段级错误文案 + 提交按钮校验禁用 | Form |
| 按钮 `Btn` | `primary`(**实心蓝**) / `ghost`(白底描边)，高 34 | Button |

## 五、领域件（任务模块）
| 组件 | 用途 |
|---|---|
| `StageStep` | 流程编排里 5 阶段开关（固定顺序，可裁剪） |
| `ConfigCard` | 编排里「每个已启用阶段」的配置卡（AI 卡 / 人工卡） |
| `MemberRow` / `MemberPill` | 成员行（可编辑：选人 + 启用 Switch + 比例 Num） / 成员只读 pill |
| `StageProgressBar` | Case 详情各阶段进度（done / doing / pending 分段） |
| `KindTag` | AI / 人工 区分小标签 |

## 六、执行页（全屏）
| 组件 | 用途 |
|---|---|
| `ExecToolbar` | 全屏顶条（52px）：左=退出 + 题目信息(bizId/进度/轮次)；右=上一题 / 下一题 + 提交标注（标注页）或 通过 / 不通过（质检页） |
| `ExecFrame` | iframe 渲染区（占满剩余）。**保存结果按钮在 iframe 内**，不在平台条 |
| `RejectModal` | 质检「不通过」弹窗（意见必填），复用 `Modal` |

## 图标
- **导航 / 装饰图标：禁用**（侧栏纯文字）。
- **功能性小图标：保留**（搜索、加号、上传、勾选、箭头、chevron 等），用于内容区可识别操作。
